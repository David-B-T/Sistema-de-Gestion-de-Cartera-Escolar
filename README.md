Nombre del proyecto: Sistema de Gestión de Cartera Escolar

Nombre del producto: LibretaDigital

Nombres de los integrantes y rol: 
David Bohórquez Toscano, desarrollador de software.
Arley Rubén Martínez Mendoza,Gestor documental.

Producto final del proyecto: Aplicación móvil en Android para la gestión local de deudas estudiantiles y sistema de notificaciones por morosidad.

Clientes: Propietario o administrador de la cafetería escolar.

Tecnologías:

Frontend: XML (Interfaces de Android) y componentes nativos de Java.

Backend: Java (Lógica de negocio y controladores en NetBeans NBANDROID).

Base de datos: SQLite (Motor de base de datos local integrado en el móvil) y MySQL (Utilizado exclusivamente para el modelado, diseño E-R y documentación académica).

Control de versiones: Git y GitHub (Implementando .gitignore y Git LFS para la correcta gestión de los binarios y recursos pesados del proyecto móvil).
