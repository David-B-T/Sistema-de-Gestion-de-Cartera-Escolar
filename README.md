Nombre del proyecto: Sistema de Gestión de Cartera Escolar

Nombre del producto: LibretaDigital

Nombres de los integrantes y rol:

David Bohórquez Toscano – Desarrollador de software (Encargado de la lógica en Java, UI/UX en XML y conexión a base de datos SQLite).

Arley Rubén Martínez Mendoza – Gestor documental / Analista (Encargado del levantamiento de requisitos, diseño del modelo E-R, normalización y documentación técnica).

Producto final del proyecto:
Aplicación móvil en Android para la gestión local de deudas estudiantiles, que permite registrar estudiantes, administrar sus saldos (aumentar, disminuir o liquidar) y emitir notificaciones automáticas en caso de morosidad.

Clientes:
Propietario o administrador de la cafetería escolar.

Tecnologías:

Frontend: XML (Interfaces nativas de Android) y componentes de UI desarrollados en Java.

Backend: Java (Lógica de negocio y controladores) – desarrollado en IntelliJ IDEA.

Base de datos: SQLite (Motor de base de datos local integrado en el dispositivo móvil) y MySQL (Utilizado exclusivamente para el modelado, diseño E-R y documentación académica).

Control de versiones: Git y GitHub, implementando .gitignore y Git LFS para la correcta gestión de los binarios y recursos pesados del proyecto móvil.
